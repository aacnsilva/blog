Personal blog generated by a small Rust static-site binary.

## Build

```bash
cargo run -- --output public
```

## Check

```bash
./scripts/check.sh
```

Runs everything CI runs: `cargo fmt --check`, `cargo clippy` with warnings denied, and `cargo test`. The tests include:

- `tests/site_contract.rs` — what the site says: pages, navigation, feeds.
- `tests/site_lint.rs` — how it is built: valid document structure, internal links that resolve, unique ids, alt text, one `<h1>` per page, canonical links, and tidy Markdown sources with complete front matter.

Clippy levels live in `Cargo.toml` under `[lints]`. Pushes to any branch run the checks; `main` only deploys if they pass.
